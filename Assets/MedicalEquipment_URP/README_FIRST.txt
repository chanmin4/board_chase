Unity 6 URP | 15 individual medical equipment prefabs
1. Assets > Import Package > Custom Package > this .unitypackage
2. Wait for editor compilation / model import.
3. Find Assets/MedicalEquipment_URP/Prefabs/P_*.prefab
4. If needed: Tools > Medical Equipment > Rebuild Prefabs.
Each prop is centered horizontally and floor-aligned with a BoxCollider.
Original GLB materials, texture and emissive screen mapping retained.
Some meshes are high-poly; use sparingly in large levels.

These assets need Unity editor import: native prefab/mesh assets are generated there.
