# Sector authoring bundle

Duplicate this set together when creating a combat room:

1. `NormalBattlePreset_Template` or `BossBattlePreset_Template`
2. `Encounter_Template`
3. One Content Profile template when the room is Normal

Then assign the duplicated preset and encounter to the matching Stage Definition entry. The assets in this folder are examples only; none is registered in a stage automatically.
