# Sector Maker — Scene 중심 작업 화면

## 처음 사용하는 순서

1. `Tools → Authoring → Sector Maker`를 연다. 위쪽 `? 사용 가이드`에서 전체 순서를 확인할 수 있다.
2. 왼쪽의 일반방 / 보스 / 무기고 / 메디컬 / 금고·보물 / 발전소 / 해치 / 탈출구 / 시작 / 홈 분류를 펼쳐 방을 선택한다. 프리팹을 상단 입력칸에 드래그하면 바로 Prefab Mode로 열린다. `SectorPresetSO`도 입력할 수 있다.
3. 목록으로 선택했다면 `Scene에서 편집 시작`을 누른다. 열려 있는 방의 `SectorRuntime`과 물체/적/루팅 위치 부모는 자동 연결된다. 별도로 Hierarchy 루트를 지정할 필요가 없다.
4. 실제 편집 화면은 Unity의 **Scene 탭**이다. Maker를 Scene 옆에 도킹하면 계속 방을 보면서 설정할 수 있다. `방 전체 보기` / `위에서 보기`로 카메라를 맞춘다.
5. 오른쪽에서 `물체 놓기`, `적 스폰 위치`, `랜덤 루팅 위치` 중 하나를 선택하고 `배치 시작`을 누른다. Scene 바닥 클릭으로 배치한다. Q/E 회전, Shift+Q/E 45도 회전, R 무작위 회전, Esc 종료, Ctrl+Z 되돌리기. Alt 카메라 조작은 배치 입력으로 처리하지 않는다.
6. 배치를 종료하고 Scene/Hierarchy에서 물체를 선택하면 `선택한 물체` 설정으로 전환한다. 위치·회전·크기를 고치거나 Scene의 W/E/R 도구를 사용한다.
7. `방 저장`을 누른다. 선택한 Prefab Stage의 프리팹과 이 방에 연결한 설정만 저장하며, 사용자 작업 씬과 다른 수정 에셋 전체를 저장하지 않는다. **Unity Prefab Mode의 Auto Save가 켜져 있으면 배치 중에도 변경이 저장된다.**

## 배치 도구 구분

- **물체 놓기:** 장애물, 장식, 항상 존재하는 상자. 배치한 프리팹 자체가 방의 자식으로 저장된다. 상자의 아이템 표는 Loot Maker에서 편집한다.
- **적 스폰 위치:** 적이 나타날 위치/방향 표시. 적 종류·웨이브·드랍은 스테이지 Encounter가 결정한다. 필요할 때 위치 부모를 자동으로 만든다.
- **랜덤 루팅 위치:** 게임 실행 시 후보 중 하나가 나타날 자리. 먼저 가운데에서 이 방의 Room Preset을 선택하고 방 전용 콘텐츠 설정을 만든다. 배치 후 위치를 선택하여 출현 확률과 후보 프리팹/비중을 넣는다. 위치 이름은 중복되지 않도록 자동 증가한다.
- 랜덤 위치의 출현 확률은 **상자 자체의 출현 확률**이며, Loot Maker의 **상자 안 아이템 확률**과 다르다.
- 룸 프리셋이 여러 개면 자동으로 하나를 선택하지 않는다. 어떤 프리셋의 콘텐츠를 편집할지 사용자가 선택한다.
- 여러 프리셋 또는 스테이지의 명시적 콘텐츠 설정이 같은 프로필을 참조하면 직접 수정을 막고 `이 방 전용으로 복사`를 제공한다. 스테이지의 별도 콘텐츠 override는 자동 교체하지 않으며 등록 확인 영역에서 안내한다.

## 방 종류 / 새 방 관리

- 왼쪽 분류는 접기/펼치기, 검색, 전체 접기/펼치기를 지원한다. 목록 오른쪽 경계를 드래그해 너비를 조절한다.
- 기본 목록에는 Rooms의 방과 연결된 프리셋의 실제 섹터 프리팹을 보여준다. 재료 프리팹 900여 개를 방으로 나열하지 않는다. 같은 프리팹이 여러 프리셋에 연결되어 있어도 목록에는 한 번만 나온다.
- Base 및 WIP는 별도의 표시 체크박스로 연다. Base를 직접 편집할 때는 자식 Variant에도 반영됨을 확인한다.
- 목록 분류는 `ProjectSettings/SectorMakerCatalog.asset`에 GUID 기준으로 저장한다. 파일 이름을 바꿔도 유지되며, 프리팹 경로·상속·스테이지 역할을 자동 변경하지 않는다. 분류/추가 등록을 실제로 수행하기 전에는 이 설정 파일을 저장하지 않는다.
- **새 Variant 만들기:** 선택한 저장된 프리팹을 부모로 하는 새 Variant 파일을 만든다. 기존 파일을 덮어쓰지 않고 사용자 작업 씬에 인스턴스를 남기지 않는다. 저장하지 않은 Prefab Stage 변경이 있으면 먼저 저장하도록 안내한다.
- **Room Preset 만들기:** 사용자가 지정한 게임 방 타입과 프리팹을 연결하는 새 설정만 만든다. 콘텐츠를 공유 복사하거나 StageDefinition에 자동 등록하지 않는다. 보스는 `SectorBossBattlePresetSO`로 만든다.
- 새 Variant는 부모를 상속하지만 이전 방의 Room Preset을 자동으로 공유하지 않는다. 새 설정과 전용 콘텐츠를 만들고 스테이지에 명시적으로 등록한다.

## 실제 게임 출현 설정

가운데 `게임 출현 / 스테이지 등록 확인`에서 이 방의 프리셋을 직접 참조하는 스테이지와 특수방 Role을 확인하고 Inspector를 열 수 있다.

- 일반방: StageDefinition → Normal Battle → Sector Presets.
- 특수방: Raid Runtime → Rooms → 해당 Role → Sector Variants.
- 보스: Boss Battles의 Sector Preset + Encounter 쌍.
- 시작: Start Sector Presets.

목록을 ‘메디컬방’으로 바꾸는 것만으로 출현 확률·적·게임 역할이 바뀌지는 않는다. 메디컬/무기고/금고의 `StageRoomType`은 Normal일 수 있으며, 역할은 `RaidRoomRole`에서 별도로 결정된다. 기존 StageDefinition과 폴더/상속은 이번 화면 개편에서 수정하지 않는다.

## 안전 장치와 검증

- 선택한 방이 실제 열린 Prefab Stage와 일치할 때만 배치/저장을 허용한다. 다른 방 선택, Prefab Mode 종료, 재컴파일 때 배치가 해제된다.
- 클릭할 바닥과 배치 부모가 같은 방 아래 있는지 확인한다. 바닥 콜라이더가 없거나 레이어가 다르면 배치가 되지 않으며 `방 점검`과 고급 바닥 레이어 설정에서 원인을 확인한다.
- 방 점검은 열려 있는 방의 미저장 내용도 읽지만 수정하지 않는다.
- 기존 고급 동선/데이터 추적 기능은 접힌 영역으로 유지한다. 기본 배치 흐름에서는 수동 부모 연결을 노출하지 않는다.
- Editor 코드 및 신규 테스트 소스 컴파일 성공. 실제 Unity **25 checks passed / 실패 0**. 결과: `Library/SectorMakerWorkspace-20260929/result-v1.txt`.
- 신규 작업 화면/안전 테스트 13개 + 기존 섹터 상속/역할 선택 테스트 5개 + UI 검사 7개를 실행했다.
- 별도 UI 창에서 입력/열기/저장 도구 표시, 가이드 클릭, 메디컬 카테고리 접기 클릭, 적 위치 도구 배치 시작/중지 클릭, 목록 너비 확대 상태를 검사했다. 마우스로 실제 바닥 클릭/드래그하거나 최종 배치 아트를 검수하는 플레이 테스트와는 별도다.
- 임시 검사에서는 테스트 프리팹/설정만 생성·삭제하고 사용자 씬의 dirty 상태, 목록 설정 파일, 실제 섹터 상속이 유지되는지 확인했다. 테스트가 바꾼 Scene 카메라와 선택도 복원했다.
- 임시 실행 파일과 meta는 Assets에서 제거했다. `Tools/SectorMaker/verify-workspace.cs.txt`에 보관한 소스는 자동 실행되지 않는다.
- 최초 Refresh에서는 임시 실행 파일의 잘못된 meta GUID로 검사가 시작되지 않았다. 이를 수정한 뒤 전체 검사가 통과했다. 실제 섹터 GUID는 변경하지 않았다.
