# Quest Maker — 퀘스트 흐름 설계

## 범위

`Tools > Authoring > Quest Maker`에서 사용한다. 기존 Quest Design Tree의 창 클래스와 스크립트 GUID는 유지한다. 인게임 퀘스트 화면 변경이 아니라 기존 QuestDefinitionSO / QuestLineSO를 편집하는 에디터 도구 개편이다.

## 화면과 사용 순서

1. 창을 열면 기존 Quest Set을 검색한다. 처음에는 ContentTemplates 밖에서 퀘스트 수가 가장 많은 기존 묶음을 보여준다. 상단 또는 왼쪽에서 다른 묶음을 선택할 수 있다.
2. 왼쪽에서 All Branches / MainQuest / StatUnlock / GearUnlock을 선택한다.
3. 새 퀘스트 이름을 입력하고 **+ Root**로 시작 퀘스트를 만든다. 선택한 카드에서 **+ Next**를 누르면 해당 퀘스트가 선행 조건인 후속 퀘스트를 만든다.
4. **+ Branch**는 선택한 퀘스트 다음에 다른 분기의 퀘스트를 만든다. 예: MainQuest → GearUnlock.
5. 기존 두 퀘스트를 이어야 하면 카드의 **Link >**를 누르고 다음 퀘스트 카드를 클릭한다. Escape / Cancel로 취소한다. 오른쪽 Links에서도 선행·후속 퀘스트를 추가하거나 연결만 제거할 수 있다.
6. 오른쪽 **Details / Goals / Rewards / Links / Check**에서 이름, 목표, 보상, 연결, 검증을 편집한다. 목표·보상 없이 흐름부터 작성할 수 있다. Validate는 미완성 내용을 경고한다.
7. **Save**로 현재 묶음과 퀘스트/참조 선행 퀘스트의 변경을 저장한다. 무관한 프로젝트 전체 에셋을 강제 저장하지 않는다.

휠은 확대/축소, 마우스 중간/오른쪽 드래그는 이동이다. 긴 체인은 처음부터 너무 작게 축소하지 않고 읽기 좋은 크기로 연다. **Fit**은 전체 개요, 왼쪽 목록 클릭은 해당 퀘스트에 초점을 맞춘다.

### 패널 크기 및 마인드맵식 편집

- 왼쪽 목록과 가운데 트리 사이, 트리와 오른쪽 Workbench 사이의 **세로 경계선**을 드래그해 너비를 조정한다. 중앙 편집 공간의 최소 너비는 보장한다.
- 조절한 너비는 프로젝트별 에디터 환경설정에 보관한다. 경계선을 더블클릭하면 해당 패널의 기본 너비로 돌아간다.
- 목록의 긴 퀘스트 이름은 줄바꿈하며, 마우스를 올리면 전체 이름과 ID가 표시된다.
- **화살표 우클릭**: `Change prerequisite (start)...`는 선행 퀘스트, `Change next quest (end)...`는 후속 퀘스트를 새로 지정한다. 메뉴를 고른 뒤 새 퀘스트 카드를 클릭한다.
- 새 연결이 확정되기 전까지 원래 연결을 유지한다. Esc / Cancel은 취소만 하고, 순환·중복·자기 연결로의 변경은 거절한다. 변경은 Ctrl+Z 한 번으로 되돌릴 수 있다.
- **화살표 우클릭 → Delete connection**은 퀘스트 에셋이 아니라 연결만 제거한다. 화살표를 클릭하여 선택한 뒤 Delete를 눌러도 된다.
- **퀘스트 우클릭**: 해당 카드에 초점 맞추기, 선행 조건 편집, 다른 퀘스트로 연결, 분기별 후속 퀘스트 생성.
- **빈 공간 우클릭**: 전체 보기, 1:1 확대, 선택 퀘스트로 이동, 분기별 시작 퀘스트 생성.
- 카드 더블클릭 또는 트리에 포커스가 있을 때 F는 선택 퀘스트에 초점을 맞춘다. 짧은 우클릭은 메뉴, 오른쪽 드래그는 기존처럼 화면 이동이다.

`Existing Quests / Set`에서 기존 퀘스트 추가와 묶음 이름 변경을 할 수 있다. Project의 QuestDefinitionSO 에셋을 트리 안에 드롭해도 된다.

## 분기 및 런타임 호환성

| Quest Maker 표시 | 기존 데이터 값 | 의미 |
| --- | --- | --- |
| MainQuest | Main = 0 | 메인 진행 |
| StatUnlock | Stats = 2 | 스탯 관련 사이드 진행 |
| GearUnlock | Item = 1 | 장비/아이템 관련 사이드 진행 |

기존 enum 값, 퀘스트 ID, 저장 데이터 구조를 변경하지 않았다. 화면 분류를 바꿀 때만 해당 QuestDefinitionSO의 기존 branch 값을 수정한다. 분기 이름이 보상 종류를 강제하지는 않는다.

화살표 A → B는 **B의 prerequisites에 A가 들어간다**는 뜻이다. 여러 화살표가 들어오면 전부 완료해야 하는 AND 조건이다. OR 선택 분기 기능은 추가하지 않았다. 자기 자신·중복·순환 연결을 막는다. 이미 잘못된 순환이 있는 에셋도 표시하여 연결을 끊을 수 있다.

분기를 필터링해도 필요한 다른 분기/다른 묶음의 선행 퀘스트는 흐린 카드로 표시한다. 외부 카드를 편집하면 원본 에셋을 수정하므로 경고를 표시한다.

**QuestLineSO는 설계용 묶음이다. NPC가 제공하는 퀘스트 목록과는 별개다.** 실제 적용 시 HomeQuestNpc의 역할과 offered quests, 기존 카탈로그 등록 흐름을 확인해야 한다. 이번 패치는 NPC 목록·기존 퀘스트 내용·게임 진행 규칙을 자동 재작성하지 않는다.

## 편집 안전장치

- 연결/해제, 분류 변경, 묶음 추가/제거 등 데이터 편집은 Undo/Redo를 지원한다.
- 새 퀘스트/복제본에는 고유 ID를 부여한다. 기존 ID는 변경하지 않는다.
- 복제 시 선행 연결은 비운다. 목표·보상 데이터는 복제한다.
- 묶음에서 제거하는 것은 에셋 삭제가 아니다. 다른 퀘스트의 참조도 유지하므로 선행 문맥으로 계속 보일 수 있다.
- 신규 목표·보상 추가 시 Unity 배열 복제에 의해 이전 대상이 몰래 복사되지 않도록 필드를 초기화한다.
- 상점 보상 노드 선택창을 보는 것만으로 빈 값/누락된 ID를 첫 노드로 덮어쓰지 않는다.
- Validate는 누락/중복 묶음 항목, ID, 선행 참조, 순환, 미작성 목표/보상, 보상 연결을 점검한다. 참조된 외부 선행 퀘스트도 검사한다.

## 코드 위치

- `Assets/Editor/QuestDesignTreeWindow.cs`: Quest Maker 창, 세 패널, 트리 조작, 목표/보상 편집 및 저장.
- `Assets/Editor/QuestMakerGraph.cs`: 레이아웃, 분기 표시, 연결 검증, Undo 가능한 데이터 편집.
- `Assets/Editor/QuestMakerInteractions.cs`: 패널 크기 조절, 화살표 선택, 우클릭 메뉴, 연결 끝점 변경, 그래프 입력.
- `Assets/Tests/EditMode/Editor/QuestMakerTests.cs`: 그래프/연결/기존 데이터 보존 회귀 검사.

테스트용 창 계측과 임시 샘플 퀘스트는 별도 Temp 검증 프로젝트에서만 사용한다. 실제 프로젝트 퀘스트 목록이나 현재 열린 씬에는 테스트 데이터를 넣지 않는다.

## 검증 결과

- 현재 프로젝트 Editor 소스 대상 Roslyn 컴파일 통과.
- 별도 Unity 6000.0.47f1 검증 프로젝트: QuestMakerTests **21개 통과, 0개 실패** (연결 이동/취소/Undo, 곡선 히트 테스트, 패널 너비 제한 포함).
- 실제 EditorWindow GUI: 1080×620 / 1280×760 / 1600×900에서 분기·편집 탭 조합 12개와 미지정 묶음 1개, 총 **13개 상태**의 외곽 레이아웃 검사 통과.
- 실제 마우스 이벤트로 `Link >`, 좌우 경계선 드래그, 연결 시작점/끝점 변경, 화살표 선택 후 Delete, 삭제 Undo, 오른쪽 드래그 이동, Esc 취소를 확인했다. GUI 오류 0개.
- 화살표 우클릭 메뉴의 대상 판정과 시작점/끝점 변경·삭제 항목 구성을 검사했다. 패널의 그리기/입력 좌표 원점을 일치시켜 좁거나 넓은 패널에서도 같은 위치에서 화살표를 선택한다.
- 원본 프로젝트 전체 게임 플레이, NPC 수락/보상 수령을 새로 통합 검증한 것은 아니다. 런타임 진행 코드와 기존 퀘스트 콘텐츠는 이번 변경 대상이 아니다.
