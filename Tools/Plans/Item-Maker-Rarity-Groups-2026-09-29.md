# Item Maker 카탈로그: 등급 그룹과 이름순 정렬

## 표시와 조작

- 기본 순서: **Normal → Rare → Unique → Legendary**, 같은 등급 안에서는 카드에 표시된 에셋 이름의 대소문자 구분 없는 A–Z 순서.
- 각 등급 제목에 현재 카테고리/검색 결과의 아이템 수를 표시한다. 제목/화살표를 클릭하면 해당 등급의 카드 격자만 접거나 펼친다. 아이템이 없는 등급은 표시하지 않는다.
- 처음에는 모든 등급을 펼친다. 카탈로그 상단 `Expand All` / `Collapse All`은 등급 그룹만 제어한다. 왼쪽 카테고리 접기 기능과 별개다.
- 접힘 상태는 프로젝트별 EditorPrefs에 저장한다. 카테고리를 바꾸거나 창을 다시 열어도 유지된다. 검색도 같은 접힘 상태를 따르므로 접힌 그룹의 검색 결과는 등급 제목의 개수로 확인하거나 펼쳐 볼 수 있다.
- 검색/카테고리 필터와 편집기 내 이름/등급 변경에 즉시 반응한다. 정렬을 위해 에셋 이름, 등급 값, GUID를 변경하지 않는다.

## 선택/드래그

- 등급을 접는 행위만으로 선택과 오른쪽 Workbench를 지우지 않는다.
- 다른 카드를 클릭하면 접힌 카드 선택은 제외한다. Shift 범위 선택과 카드 드래그는 펼쳐진 카드만 대상으로 삼는다.
- Ctrl/Command 다중 선택과 선택한 여러 아이템의 기존 카테고리 이동 처리를 유지한다.
- Project에서 아이템을 선택하거나 생성/복제/이동 후 선택하면 그 아이템의 등급을 펼쳐 찾을 수 있게 한다.

## 구현

- `Assets/Editor/ItemMakerCatalogView.cs`: 명시적 등급 순위, 이름 비교, 접힘 상태, 표시 아이템 목록. 런타임 `PlayerShopItemRarity`는 Legendary=2, Unique=3이므로 숫자 값을 재배치하지 않고 표시 순서만 별도로 정의한다.
- `Assets/Editor/ItemMakerWindow.cs`: 등급 헤더/색상 표시, 그룹별 카드 격자, 범위 선택의 표시 순서 연결.
- `Assets/Tests/EditMode/Editor/ItemMakerCatalogViewTests.cs`: 순서/이름 비교, 실시간 변경, 기본 펼침/저장, 전체 접기, 가려진 선택 제외, Ctrl 선택, 미지정 미래 등급 표시 회귀 검사. 테스트 아이템은 메모리에서만 만들고 제거한다.

런타임, 실제 아이템/루팅 테이블, 프리팹, 씬은 변경하지 않는다.

## 검증 결과

- 에디터 컴파일 통과, 실제 Unity 검사 **35개 통과 / 실패 0개**.
- 신규 카탈로그 회귀 테스트 9개 + 기존 트리/사이드바 회귀 테스트 11개 + 별도 창의 GUI/검색/실시간 편집 확인 15개.
- 실제 MouseDown/MouseUp으로 전체/개별 접기와 펼치기, 다시 열었을 때 접힘 복원 확인. 기본 등급 순서와 카드 배치, 선택 유지, 검색 및 빈 결과, 메모리상 아이템 등급 변경 시 재배치를 확인했다.
- 실제 에셋을 만들거나 수정하지 않았으며 Project 선택도 변경하지 않았다. 검사 후 기존 등급 EditorPrefs를 복구하고 임시 창/아이템을 제거했다.

- 임시 실행 스크립트/메타는 Assets에서 제거. 수동 재현 소스: `Tools/LootMaker/verify-item-catalog-rarity.cs.txt`.
