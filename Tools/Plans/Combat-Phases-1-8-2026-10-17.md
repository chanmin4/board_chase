# 전투 시스템 단계별 반영 — 2026-10-17

사용자 요청: 1~8단계. 7단계는 시스템만, 8단계는 방탄 드롭 내구도만. 섹터 제작·상품 등록·퀘스트·최종 밸런스(9~10단계)는 제외한다.

## 상태와 경계

소스 수정 반영 상태다. 사용자 요청에 따라 C# 빌드, Unity 컴파일 확인, 자동 테스트, Play Mode 검증을 실행하지 않았다. 동작 검증 완료를 의미하지 않는다. 기존 미커밋 변경은 되돌리지 않았으며, 섹터/프리팹/SO 콘텐츠 자산을 자동 수정하지 않았다.

## 1. 플레이어 스태미나

- `ShooterStaminaRuntime`: 플레이어/적 공통 소모·회복·고갈 처리. Shooter Config의 Locomotion 설정을 읽는다.
- 현재값: 기본 풀 200, 달리기 초당 15, 대시 1회 40, 초당 회복 15, 소모 후 회복 대기 0.75초, 고갈/재개 기준 10%.
- 걷기는 기존 MoveSpeed × 1, 달리기는 × 1.5. 걷기 대비 50% 증가다. 절대 이동 속도는 각 캐릭터의 기존 MoveSpeed를 사용한다. 2026-10-20 최신 요청으로 코드 기본값과 플레이어/적 Shooter SO 13개의 실제 이동 설정을 함께 저장했다. 이전에는 코드 기본값만 바꿨고 SO 파일에는 이동 블록을 저장하지 않아 에디터의 기존 직렬화 상태에 예전 값이 남을 수 있었다.
- 달리기 기본 입력: Left Shift 유지. 기존 저장 대시가 Left Shift이면 새 달리기만 Left Ctrl로 피한다. 기존 대시/사용자 바인딩은 덮어쓰지 않는다. 설정 화면에 달리기 재지정 항목 추가.
- 사격·재장전·소모품·근접·투척 제한 연결. 정조준·재장전·소모품·근접 동작 중에는 새 달리기를 시작하지 않는다. 대시는 별도 소모 행동이다.
- 런타임 스태미나 HUD 추가. 입력 레이캐스트를 받지 않는다. SO Maker 능력치 탭에 공통 이동·스태미나 설정 노출.

## 2. 적에게 공통 규칙 적용

- 동일 런타임/소모량/회복량, 기본 풀 배율 2 = 400. 보스도 우선 같은 2배이며 Config에서 따로 변경 가능하다.
- 순찰은 걷기. 추적 중 12m 이상에서 달리기, 8m 안으로 접근하면 해제하는 임시 기준. 실제 이동 경로가 있고 행동 가능한 경우만 요청한다.
- 사격 시작 시 달리기를 종료한다. 적별 사용 ON/OFF와 거리 설정 제공. 적 고유 무장/전술/HFSM은 유지한다.

## 3. 정조준 행동·시야 표현

- 정조준 진입/해제 중 발사 금지, 전환 중 달리기 금지.
- 기존 원+부채꼴 시야, 조준 축소, LOS 판정을 유지한다.
- 같은 시야 경계에 일반 테두리 추가. Aim01에 따라 테두리를 밝게 하고 바깥 안개 알파를 추가한다.
- 기본 테두리 2px, 조준 추가 안개 알파 0.18. `PlayerVisionFogOverlayUI`에서 ON/OFF·색·폭·암화 조정.

## 4. 정조준 헤드샷

- 완전 정조준 때 발사 순간 카메라의 마우스 레이가 가리킨 적 Shooter 캡슐 대상을 저장한다. 앞쪽 다른 물체는 후보 선정을 차단한다.
- 기본 탄환(BasicBullet 및 같은 경로의 산탄 등)에 후보와 무기별 배율을 복사한다. 실제 충돌 대상이 같을 때만 HP 피해 입력을 증폭한다. 관통/방탄 규칙은 그대로 거친다.
- 무기별 `HeadshotDamageMultiplier` 초기 1.5. 힙파이어는 미적용. 폭발/특수 투사체에는 별도 헤드샷을 넣지 않았다.
- 실제 HP 피해가 발생한 헤드샷에 source/target/kill 여부 이벤트 제공. 퀘스트 연결은 9단계로 남긴다.

## 5. 반동·피격 흔들림

- 현재 조준 방향 반대쪽 ±45도에서 발사 반동. 마우스 기준 방향과 별도 누적 오프셋을 사용하며 입력을 계속 반영하면서 회복한다.
- 초기 반동 거리 0.35, 피격 거리 0.65, 누적 상한 2, 초당 회복 거리 2.5.
- 적은 직접 피해 후 0.35초간 추가 탄퍼짐 8도. 출혈 등 주기 피해는 흔들림을 발생시키지 않는다.
- Shooter Config의 AimFeedback / SO Maker 반동·피격 흔들림 설정에서 수정한다.
- 무기 SO에는 발사 반동 거리·누적 상한·회복 속도 배율을 별도로 제공한다. 초기 배율은 모두 1이며 기존 자산 수치는 자동 수정하지 않았다.

## 6. 파괴 가능한 엄폐

- `SectorDestructibleCover`: 명시적으로 지정한 구조물만 사용. 초기 내구도 500. 일반 기본 탄환의 물리 충돌 지점에서 탄환 피해를 받는다.
- 내구도 0이면 해당 배치 오브젝트를 비활성화해 Collider/Renderer/시야 차단/자식 엄폐 지점을 함께 제거한다. 다른 구조물로 전파하지 않는다.
- 섹터의 기존 NavMesh를 비동기 갱신한다. 같은 시점의 여러 파괴 요청은 섹터별로 묶는다.
- 같은 레이드의 부분 손상과 파괴 상태를 저장 데이터에 기록한다. 재진입/이어하기 시 다시 추첨하거나 회복하지 않는다. 정상 레이드 체크포인트 저장 주기를 사용한다.
- Sector Maker에 이번 배치 파괴 엄폐/내구도 및 선택 물체 ON/OFF 추가. 기존 배치물은 자동 변경하지 않았다. 체력바·파손 단계·별도 연출은 없다.
- 생성 시 복구는 NavMesh 빌드 전에 수행한다. 배치 ID가 비어 있으면 기존 컨테이너처럼 상대 계층 경로를 사용하므로 배치 변경 후 기존 세이브 호환은 별도 고려해야 한다.
- 공용 파괴 연기: `Assets/Resources/SectorDestructionEffects.asset` 한 곳에 등록한다. 기본 프리팹은 기존 `SmokeArcExplosionDark`. 구조물별 파티클 컴포넌트 추가는 필요 없다.
- 파괴 직전 모델 Renderer의 월드 Bounds 중앙(없으면 Collider, 최종 fallback은 피벗)에서 1회 생성한다. 바닥 X/Z 중 긴 변과 공용 기준 지름에 비례해 균등 확대한다. 추가 배율과 최소·최대 배율을 조정할 수 있다.
- 이펙트는 사라지는 구조물의 자식이 아니며 재생 완료 후 제거한다. 저장에서 이미 파괴된 물체를 복원할 때는 연기를 재생하지 않는다. `Tools/Effects/엄폐 파괴 연기 설정`으로 공용 설정을 연다.

## 7. 특별 섹터 시스템만

- StageDefinition의 SpecialSectors 설정: 기본 비활성. 종류 ID/가중치, 종류별 변형 ID/프리셋/가중치, 최소·최대 등장 수 설정.
- 종류를 먼저 뽑고 해당 종류의 변형을 선택한다. 한 종류는 한 레이드에 최대 한 번. 일반 방 중 해치·보스·발전기·금고·상인·탈출 후보를 제외하고 배정한다.
- 수락했고 아직 완료하지 않은 퀘스트에 연결된 종류는 먼저 보장한다. 필수 수량이 상한/방 수를 초과하거나 등록이 빠졌다면 명시적인 이유와 함께 생성 실패 처리한다.
- 선택한 종류/변형 ID를 방 노드에 저장한다. 이어하기 시 가중치·활성 설정에 따라 재추첨하지 않으며, 사라진 ID는 조용히 대체하지 않는다.
- 기존 고정확률 → 후보 가중치 → 생성 상한/저장 방식은 재구현하지 않고 유지한다.
- 실제 섹터 프리팹, 테마, 배치, 아이콘 아트, 적/루팅 테이블 등록은 사용자 작업으로 남겼다.

## 8. 적 방탄 드롭 내구도만

- 초기 절대값: 일반 적 350~500, Boss 역할 500~650. 최대 내구도 1,000에 맞춘 임시 초안이며 Enemy Config에서 수정 가능하다.
- 착용 방탄은 사망 시 품질 상한을 한 번 추첨한 뒤 전투 후 남은 내구도와 비교해 낮은 값을 드롭한다. 죽으면서 수리하거나 파괴된 방탄을 되살리지 않는다.
- 추가 랜덤 방탄 드롭에도 같은 범위를 적용하고 시체 인벤토리/바닥 드롭 양쪽에 같은 확정 내구도를 전달한다.
- UI 갱신은 품질을 재추첨하지 않는다. 방탄 획득 후 원본 장비도 비워 다음 동기화로 다시 나타나지 않게 한다.
- 상점·상품·가격·수리 정책·기존 흡수 피해 내구도 공식은 이번 단계에서 변경하지 않았다.
