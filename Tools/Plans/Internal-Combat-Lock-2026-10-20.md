# 내부 잠금 전투 구역 — 사전 배치 버전, 2026-10-20

## 최신 방향

사용자 요청으로 이전 런타임 벽/패널 생성 방식과 자동 위치 축소를 제거했다. 이 문서가 이전 생성형 설명을 대체한다. 벽·패널·스폰 위치는 프리팹에 고정 저장하며, 실행 중에는 잠금 트랜잭션과 하강 연출만 처리한다. 원정/섹터 자체의 기존 인스턴스 생성이나 일반 루팅 스폰 시스템을 없앤다는 뜻은 아니다.

## Treasure_01 사전 배치

- 수정 대상: Assets/Prefabs/GameScene/Sector/Rooms/Treasure/Treasure_01.prefab.
- 중앙 153.6 × 153.6의 벽 외형을 고정 배치했다. 사용자 요청으로 각 DOOR의 Y Scale을 8(외형 높이 약 17.6)로 늘렸다. 바닥 192 기준 외곽 각 방향 여유는 19.2를 유지한다. 실제 통행 폭은 벽/외곽 콜라이더 두께만큼 줄어든다.
- LoweringWallVisuals 아래 동서남북에 SM_Walls_Door_06 프리팹을 각각 3개씩, 총 12개로 이어 붙였다. 각 조각 폭은 51.6으로 맞추고 각 면의 전체 길이 154.8을 유지한다. 동서 면의 배치 축은 Z, 남북 면은 X를 사용하며, 모델 로컬 X를 각 면 방향으로 회전한다. 공유 원본 벽 프리팹은 수정하지 않았다. 고정 Collider/NavMeshObstacle 높이는 18로 함께 올렸다.
- FixedBlockers_UntilFullyLowered는 별도의 고정 루트다. 네 면의 BoxCollider, NavMeshObstacle, 시야 차단 ON, NavMesh 빌드 제외 설정을 미리 저장했다.
- 동서남북 LockPanel 네 개에 SM_Props_12 외형·근접 트리거·공유 Area 참조를 저장했다. 원본 패널 프리팹은 수정하지 않았다.
- 외곽 테스트 진입점도 프리팹에 저장했다.
- 외곽 통로 확대에 맞춰 네 패널과 외곽 테스트 진입점, 네 면의 고정 판정 크기/위치를 함께 조정했다. 줄어든 내부 범위 가장자리의 적 스폰 지점 4개도 프리팹에서 안쪽으로 옮겼다. 루팅/일반 구조물은 이동하지 않았다. 실행 중 자동 배치는 없다.

## 잠금 해제 순서

1. 잠긴 동안에는 외곽 통행 가능. 섹터에 진입하면 해제 전부터 내부 적을 미리 스폰한다. 기존 최대 동시 생존 수를 유지하고 초과분은 기존 대기 큐를 사용한다.
2. 네 패널 중 하나에 접근하여 E를 누른다. 기존 상점 거래형 Key Tool 열쇠 드래그/확인 UI를 사용한다.
3. 취소/불일치/거리 이탈/다른 섹터/사망에서는 해제하지 않는다. 확인 시 열쇠 사용 횟수를 한 번 소모하고 공유 해제 상태를 저장한다.
4. 외곽 이동 포탈을 잠그고 네 패널의 상호작용을 종료한다. 패널 외형은 남는다.
5. 저장된 벽 외형만 0.8초 동안 아래로 20 이동한다. 높아진 벽 전체가 바닥 아래로 내려가도록 거리를 늘렸다. 고정 차단 루트는 이동하지 않는다. 따라서 연출 도중 시야·플레이어/적 이동·총알 차단은 유지된다.
6. 하강 완료 프레임에 벽 외형과 고정 차단 루트를 함께 비활성화한다. 시야·물리 충돌·NavMesh carving을 함께 해제한다. 적은 이후 외곽으로도 이동할 수 있다.
7. 전멸은 기존 섹터 클리어 처리로 연결하고 이동 포탈을 다시 연다. 잠금/하강 중에는 클리어를 확정하지 않는다.

이어하기에서 이미 해제된 방은 하강 완료 상태로 복원하며 열쇠를 재소모하지 않는다.

## 제작 도구와 오류 처리

Sector Maker는 사전 배치 참조/하강 값만 수정한다. 벽/패널 자동 생성·재생성 버튼과 실행 중 콘텐츠 자동 축소를 제거했다. 외형과 고정 판정은 같은 섹터의 독립 루트로 지정하고, 패널은 그 밖에 둔다. 다른 특별 섹터에도 같은 작성 방식을 사용할 수 있다.

StageSectorInstantiator는 작성된 컴포넌트에만 Bind한다. 작성된 벽/고정 판정/패널이 없으면 명확한 오류를 내며 생성에 실패한다. 누락된 오브젝트를 실행 중 임의 생성하지 않는다. 새 원정 금고의 내부 잠금 모드와 기존 저장의 포탈 잠금 호환 경계는 유지한다. 프리팹을 명시적으로 내부 잠금 방식으로 변경한 경우 해당 작성이 적용된다.

Debug Monitor Stage & Start Hub의 진행·전투 시스템 연결에서 현재 원정의 미개방 잠금방 외곽으로 이동할 수 있다. 금고 출현 확률/열쇠 지급/잠금 해제 자체를 우회하지 않으며, 이번 원정에 대상이 없으면 안내한다. HOME 전투 실험실은 원정 잠금 트랜잭션을 갖지 않으므로 이 테스트는 실제 원정에서 진행한다.
