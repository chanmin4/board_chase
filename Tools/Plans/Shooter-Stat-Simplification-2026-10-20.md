# Shooter 스탯 간소화 · 2026-10-20

후속 변경: 사격/조준/발사 반동 기본값은 `Weapon-Owned-Stats-2026-10-20.md`에 따라 무기 SO로 이관했다.
이 문서의 공통 반동 설명은 피격 흔들림만 해당하며, 패시브 허용 대상에는 새 발사 반동 3종이 추가됐다.

## 적용 범위

- 사용자 승인: 폐기 스탯 계산 경로 제거, 탄창/근접 피해 무기 소유, 대시 스탯 통합,
  플레이어/적 공통 소지 용량, 공통 규칙 공유 및 접힌 Override UI, AI 설정 접기, 패시브 대상 제한.
- 기존 dirty checkout의 다른 변경은 유지. Notion/씬/프리팹 및 저장 파일은 수정하지 않음.
- 이번 작업에서는 빌드, 테스트 실행, Unity 실행, AssetDatabase.Refresh를 수행하지 않음.

## 데이터 소유권

- 탄창: RangedWeaponSO.MagazineSize. 캐릭터/패시브/방탄/탄환 modifier의 MagazineSize는 미지원.
  플레이어/적 장전 경로와 런타임 표시가 동일한 값을 사용한다. 추후 파츠는 무기 측에서 해결해야 한다.
- 근접 피해: 기존 Combat Knife/MeleeWeaponSO. 플레이어 SO의 옛 주먹 피해는 숨긴 호환 필드만 유지.
- 소지 용량: ShooterStatConfigSO.Inventory의 포켓/기본칸 + BackpackItemSO의 추가칸.
  플레이어 기존 2+4+가방 유지. 적은 SO별 기존 총 칸 수를 포켓 2+나머지 기본칸으로 보존.
  구조물 루팅 용량은 명시적 ConfigureInventoryCapacity 값이 우선한다.
- 적 가방: 공통 용량 정책과 이동 배율 hook만 준비. 자동 착용/획득 AI나 시체 가방 cargo 이전 UI는 추가하지 않음.
  해당 기능은 실제 가방 소유·저장·이전 처리를 함께 구현한 뒤 활성화해야 한다.
- 대시: ShooterStatConfigSO.Dash가 속도/시간/쿨타임/회전/기울임을 소유.
  DashConfigSO와 옛 참조는 WIP 호환 데이터로만 남기며 새 제작 목록에서 제외.
  기존 플레이어/적 프리팹에서 사용한 이동 기준 배율 1.8, 지속 .3초를 스탯에 저장.
  플레이어 쿨타임 3초, 적은 기존 개별 AI 설정 4초(Agent 5초)를 통합 스탯으로 이관.
  기존 적 런타임의 공통 기본 DashCooldownSeconds=0 경로는 더 이상 사용하지 않는다.

## 공통 규칙

- Assets/Resources/ShooterCommonRules.asset을 실제 13개 Shooter SO에 연결.
- 이동/소모/회복, 반동/피격 흔들림, 적 공통 시야, 방탄 드롭 범위를 공유.
- 최대 스태미나는 캐릭터별 직접 값: 플레이어 200, 적 400.
- 적 달리기 사용/시작/종료 거리는 개별 AI 설정으로 유지.
- 플레이어의 기존 시야 모양/정조준 비율은 유지. 적은 공통 시야 또는 기존 개별 시야 Override 사용.
- 공통값은 캐릭터 Inspector와 Character Status Maker의 접힌 공통 규칙에서 읽기 전용으로 확인.
  전체 수정은 원본 SO, 개별 수정은 묶음별 Override ON.
  첫 Override 활성화 시 공통값을 복사하며, 이후 OFF/ON 시 저장한 개별값을 유지한다.
- AI 판단 로직/FSM은 바꾸지 않고 탐지·이동·근접·투척·대시·사격 그룹으로 접어서 표시.
  별도의 공유 AI 프로필 SO나 새 FSM은 이번에 도입하지 않았다.

## 폐기 및 제한

- 스탯 enum의 기존 숫자와 오래된 직렬화 필드는 삭제/재정렬하지 않음.
- 마크, 일반탄 감염, 옛 조준 거리/이속/반동/원형 퍼짐의 modifier 계산을 제외.
  일반탄 마크/감염 계산 함수는 0 반환 호환 stub. 감염 회복·가스·주입 DOT는 유지.
- 플레이어 스냅샷은 재계산 시작 시 초기화하며 옛 값은 숨김. 새 반동 AimFeedback은 유지.
- 공통 ShooterStatPolicy로 런타임과 제작 선택 목록을 제한한다.
- 패시브 허용 대상: 피해, 사거리, 연사, 이속, 시야 거리, 최대 체력, 대시 거리/쿨타임,
  재장전, 회피, 조준 속도, 일반/정조준 퍼짐, 기본 방탄, 추가 관통.
- 기존 사거리/회피 패시브는 유지. MagazineSmall/Middle/Large의 탄창 증가 효과는 제외되지만
  원본 아이템/소유권/저장 데이터는 삭제하지 않는다. Maker에서 미지원 값으로 표시한다.
- 랜덤 패시브의 미지원 행은 0 효과로 남겨 아이템 자체가 사라지지 않게 한다.
