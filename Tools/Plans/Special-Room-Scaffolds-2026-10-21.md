# 특별맵 빈 틀 / 1스테이지 테스트 등록

## 작성 범위

사무실(Office), 창고(Warehouse), 서버실(Server)은 기존 완성 방 프리팹이 없어서
Sector_Base를 상속한 빈 프리팹과 SectorPreset SO를 추가했다.
바닥·외벽·포탈·적 스포너는 공통 베이스를 사용하고,
각 방에는 적 스폰 포인트 9개를 프리팹에 미리 저장했다.
가구 배치 예정 그룹은 이름과 위치만 있는 빈 GameObject다.
가구, 루팅 상자, 고유 루팅 테이블은 아직 작성하지 않았다.
런타임에 가구/벽을 자동 작성하는 코드는 추가하지 않았다.

기존 Armory_01(보안실), Medical_01(응급의료실), Treasure_01(잠금보관실)은
복제하거나 수정하지 않고 기존 SectorPreset을 그대로 재사용한다.
기존 잠금보관실을 작은 중앙 금고/남쪽 패널 1개 형태로 변경한 작업은 아니다.

## 등록 상태

Stage1Definition의 특별맵 풀에 office / storage / security / medical / vault / server를 등록했다.
현재는 비율 모드(특별 30% / 일반 70%)이며, 초반 테스트용으로 사무실·창고만 ON이다.
보안실·응급의료실·잠금보관실·서버실은 등록을 유지하고 체크 OFF로 두었다.
종류 중복은 OFF이므로 목표 개수가 2개를 넘으면 부족분은 일반방으로 채운다.
처음의 6종 각각 1개 강제 테스트 설정은 해제했다. 개수 제한은 기본 적용하지 않는다.
발전실·해치·외곽 탈출 등 기존 필수방 설정은 유지한다.
기존 별도 금고 후보 추첨(vaultNearCandidateChance)은 0으로 내려
특별맵 vault와 중복되지 않게 했다. vault 풀은 기존 내부 잠금 프리팹을 사용한다.
2~6스테이지와 맵 크기, 일반방 풀, 테마/공통방 비율은 변경하지 않았다.

새로 생성한 맵에 적용되며 기존 레이드 저장 맵을 재추첨하지 않는다.
플레이 테스트는 진행 중 레이드 이어하기가 아닌 새 레이드로 시작한다.

## 확인 방법

1. Tools > Authoring > Stage Maker에서 Stage1Definition 선택.
2. 등장할 맵 · 특별방 구역에서 비율과 종류별 체크 확인.
3. 랜덤 생성으로 목표/실제/일반방 대체 수량을 확인한다. 모든 종류를 시험하려면 체크를 켠다.
4. 새 레이드에서 방 진입, 적 생성/클리어, 포탈 이동 확인.
5. Sector Maker/Prefab Mode에서 Office_01, Warehouse_01, Server_01을 열어
   배치 예정 그룹 대신 실제 구조물/루팅 오브젝트를 작성한다.

공통 베이스를 수정하면 새 3종에도 반영된다.
특정 방만 수정할 때는 각 방의 variant를 편집하고 공통 베이스에 Apply하지 않는다.

## 검증 경계

에셋 YAML의 로컬 fileID, GUID, 스폰 지점 부모, Stage SO 등록 내용을 정적으로 점검한다.
Unity 임포트, 컴파일, 미리보기 실행 및 Play Mode 결과는 별도 확인이 필요하다.
