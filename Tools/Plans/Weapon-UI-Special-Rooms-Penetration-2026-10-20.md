# 장착 무기 UI / 특별방 설계 / 현재 관통식

> 이 문서의 관통식과 방 수량 제안은 수정 전 기록이다. 이후 승인된 관통식 변경과20/30/50 방 비율 검토는 `Stage-Room-Frequency-And-Penetration-2026-10-20.md`를 따른다.

## 이번에 적용한 범위

기존 아이템 상세 패널의 장착 무기 성능 목록을 수정했다. 별도 스탯 메뉴나 파츠 시스템은 추가하지 않았다. 프리팹 배치, 방 추첨 설정, 관통 밸런스, Notion은 변경하지 않았다.

- 실제 활성 무기를 선택하면 `무기(무기 자체 보정 포함) + 패시브 [+ 기타] = 최종값`으로 표시한다.
- 반동·상한·복구·조준속도·연사·재장전·탄퍼짐·사거리·추가 관통·총성 반경을 표시한다. 탄창은 무기 고정값이다.
- 반동/퍼짐/재장전/총성 반경 감소는 초록, 증가하면 빨강이다. 복구/조준속도/연사/사거리/관통은 반대이다.
- 같은 SO를 쓰더라도 상점·전리품·가방·비활성 무기에 현재 활성 무기의 최종값을 붙이지 않는다. 플레이어 소유자와 활성 장착 슬롯을 확인한다.
- 기존 전투 계산 순서/배율/Override 우선순위는 유지한다. 같은 계산기에 무기만의 누적값과 패시브 제외 누적값을 함께 보관한다.
- 패시브 증분은 다른 지속 보정을 유지한 채 패시브 유무 차이로 계산한다. 퍼센트와 최솟값 제한도 반영한다. 최종값에서 남는 차이는 기타(퀘스트/장비/탄약/내구도/상태)로 분리한다. 복합 보정이 있을 때 이 증분은 SO 원문 수치의 단순 합과 다를 수 있다.
- 실제 반동 단위는 거리다. 0.35를 임의로 35로 환산하지 않았다. 사용자 예시의 35 + 13 = 48은 표시 구조 예시다.
- 선택한 장착 무기만 0.2초 간격의 unscaled 시간으로 갱신한다. 매번 씬 전체를 검색하지 않는다.

정적 확인: 대상 diff 공백 검사와 호출/필드 연결 확인. EditMode 회귀 테스트 소스 6개 사례(평면/퍼센트/최솟값/Override/기타 장비 분리/비장착 선택)를 추가했다. Unity 컴파일·테스트·Play Mode는 실행하지 않았다.

## 콘텐츠 구성 제안 — 아직 미적용

사무실: 책상·책장·칸막이, 문서 계열 루팅.

창고: 컨테이너·지게차·박스가 올라간 물품 선반, 일반 물자.

비상발전실(전기실): 발전기와 엔진실 구성. 기존 발전소 역할과 통합해 중복 추첨하지 않는 방향.

보안실: 무기 보관함·락커·대형 모니터·여러 소형 모니터.

응급의료실: 병상·의료기구·의료 루팅.

잠금보관실: 작은 중앙 금고 잠금구간, 남쪽 패널 하나, 주변 루팅 오브젝트. 외곽은 문서 책장·모래포대·구조물·적 스폰이 있는 일반 전투 공간.

서버실: 서버 랙과 설비를 모은 특별방 종류. 실제 제작한 섹터 프리팹/SectorPreset을 독립 풀에 등록해야 한다. 현재 서버 프리팹을 임의 생성하거나 다른 방을 서버실로 위장 등록하지 않았다.

### 금고방 구현 시 함께 바꿔야 하는 기존 규칙

현재 SectorLockedCombatArea는 네 패널을 필수 검사하고, 내부만 적 스폰 후보로 허용하며, 잠금 중 섹터 클리어를 막고 외곽 이동을 허용한다. 따라서 프리팹 크기나 패널 수만 바꾸는 것으로는 새 설계가 성립하지 않는다.

새 금고는 `내부 잠금 전투구역`과 다른 `보관함 잠금구역` 모드가 필요하다.

- 외곽 적 스폰은 일반 섹터 규칙을 사용한다. 내부 금고 안에는 적을 강제 배정하지 않는다.
- 외곽 적을 전멸하면 섹터 클리어, 포탈 개방. 금고를 안 열어도 통행할 수 있다.
- 중앙 금고 해제는 열쇠 제출/벽 하강/루팅 개방만 담당한다. 완료한 섹터를 다시 미클리어로 만들지 않는다.
- 남쪽 패널 1개를 사전 배치한다. 기존 전투 잠금방 4개 패널 모드와 호환되는 검증 정책을 둔다.
- 벽은 프리팹에 미리 배치한다. 외형만 빠르게 내려가고, 완전히 내려간 순간 고정 시야/이동/총알 차단을 함께 해제한다. 실행 중 벽을 생성하지 않는다.
- 금고 크기는 콘텐츠가 들어갈 만큼만 줄이고, 중앙 잠금 범위와 적 스폰 범위를 별도 설정한다.

### 추첨 초안

1스테 테스트 기준 제안이지 적용값/확정값이 아니다.

- 일반 특별방: 최소 2, 최대 3. 사무실·창고·보안실·응급의료실·서버실 중 종류를 중복 없이 선택한다. 종류를 고른 다음 그 종류 안에서 변형 프리팹을 가중치 추첨한다.
- 비상발전실: 기존 발전소 기능을 유지하며 별도 필수 1개. 일반 특별방 2~3개 수량과 분리한다.
- 잠금보관실: 별도 최소 0, 최대 1. 생성 여부를 먼저 고정 확률로 추첨하고, 생성할 경우 유효 위치 중 가중치 추첨한다. 시험 확률 50% 정도부터 조정할 수 있다.
- 위치는 나침반 방향을 고정하지 말고 시작점으로부터 실제 포탈 경로 거리와 사분면 분산을 사용한다. 사무실/의료는 중간, 창고/보안은 중간~외곽, 서버/금고는 외곽 우선. 범위는 맵 실제 최대 경로 거리 비율로 설정한다.
- 시작/해치/보스/발전실/탈출 예약 위치 중복 금지. 가능하면 특별방끼리 인접하지 않고 서로 다른 방향에 분산한다. 이 간격은 우선순위, 필수 수량과 핵심 경로 유효성은 강제 조건이다.
- 퀘스트 필수 종류 먼저 확보하고 선택 수량 안에 포함한다. 필수 종류가 최대 수량을 넘거나 유효 프리팹이 없으면 작성 도구에서 사전 경고한다.
- 내부만 잠겨 있으므로 금고 섹터가 그래프 말단일 필요는 없다. 통행이 잠금벽을 통과하지 않는지만 보장한다.
- 시드 결정 및 선택한 위치/종류/변형 저장을 유지하고, 재진입·로드 시 재추첨하지 않는다.

현재 코드 상태: StageSpecialSectorSettings는 전체 최소2/최대3, 종류별 가중치/변형 가중치/퀘스트 필수 보장이 있다. 종류별 최소·최대와 방향/거리 배치는 없다. 현재 Stage1~6Definition 에셋에는 `_specialSectors`가 작성되어 있지 않아 기본 disabled 상태다.

현재 V3 금고는 별도 생성 경로다. 네 원거리 후보 각각에 25%로 근처(경로2 이하)의 일반 방을 금고로 지정하려 시도한다. 최소 보장 없이 이론상 0~4개이며 후보 방 부족 시 더 줄어든다. 제안한 0~1개 상한과는 다르므로 향후 이 경로를 대체/통합해야 한다. `_treasure.minCount/maxCount`는 V3 금고 수량 설정이 아니다.

## 현재 총알 관통식 — 변경 없음

유효 관통 P = max(0, 탄약 관통 + 현재 무기의 최종 추가 관통). 추가 관통에는 패시브 등 현재 보정이 포함되며 소수점이 유지된다.

현재 레이드 V3는 RaidArmorPenetration을 사용한다. A는 보호 중인 실드(있으면 우선) 또는 착용 방탄 등급에 캐릭터 기본 방탄/델타를 더한 값이다. 방탄복+실드 등급을 동시에 더하거나 여러 번 관통 추첨하지 않는다.

```text
g = max(0, A - P)
c = clamp01(현재 보호장비 내구도 / 최대 내구도)
q = min(0.95, max(0.05, 0.95 × 0.54^g) + (1-c) × 0.15)

랜덤 0~1 < q 이면 관통 성공
성공 HP 피해 배율 = max(0.50, 0.90 - 0.10 × g)
실패 HP 피해 배율 = max(0.20, 0.30 - 0.05 × g)

A <= 0이면 추첨 없이 HP 피해 배율 1
```

신품 방탄, 입력 피해100, 별도 피해배율 없음, 충분한 방탄 내구도 기준:

| 방탄-관통 차이 g | 관통 성공률 | 성공 시 HP | 실패 시 HP |
| --- | --- | --- | --- |
| 0 | 95% | 90 | 30 |
| 1 | 51.3% | 80 | 25 |
| 2 | 27.702% | 70 | 20 |
| 3 | 14.95908% | 60 | 20 |

```text
희망 흡수량 = max(0, 입력 피해 - 입력 피해 × HP 피해 배율)
실제 흡수량 = min(희망 흡수량, 현재 방탄 내구도)
방탄 내구도 감소 = 실제 흡수량
HP 전달 피해 = 입력 피해 - 실제 흡수량
최종 HP 피해 = HP 전달 피해 × 최종 받는피해 배율 × 상태 받는피해 배율
```

예: 피해100 중 HP20/흡수80 판정이면 내구도80 감소. 남은 내구도가30뿐이면30만 흡수하고 HP70. 특수 실드는 별도 마모 경로(성공 시 입력피해×1, 실패 시 ×0.35)를 유지한다.

주의: 현재 V3는 관통이 방탄과 같거나 훨씬 높아도 g=0이라 최대 성공률95%, 성공 피해90%다. 즉 방탄이 살아 있는 동안 관통 초과분이 추가 이익을 주지 않는다. 이 부분은 새 관통 설계에서 의도적으로 유지/변경을 결정해야 한다.

레이드 V3 이외의 기존 경로는 다르다. 방탄이 관통보다 높으면 `최소 배율 = 0.10 + 0.90 × exp(-0.55 × g)`부터1 사이에서 피해배율을 균등 추첨한다. 같거나 높으면 배율1이다. 기존 경로는 실드/방탄복/기본 방탄 각 단계가 남아 있으므로 V3와 동일한 식이라고 보면 안 된다.
