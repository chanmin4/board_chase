## 1. 전투·성장·퀘스트 시스템 — 코드 반영

- 기본 플레이어 HP100·공격30. 탄약 보정은 T1~8에서 0/-2/-3/-4/-5/-6/-7/-8. 기존 무기·모듈 보정 경로에 연결했다. 일반 호환 슈터의 절대 탄 피해 필드는 보존했다.
- 관통 확률은 0.05 + 0.90 × (exp(2.5r)−1)/(exp(2.5)−1), r=clamp(P/A,0,1). 성공 피해 50~100%, 실패 15%. 동급 이상도 성공 확률 95%. 방탄 없는 대상은 100% 피해.
- 방탄/탄약 수치 30/37/44/51/59/67/76/85. 방탄 등급은 별도 EquipmentTier로 유지해 적 장비 추첨이 숫자 방탄력과 혼동되지 않게 했다. S2/S3는 같은 장비 추첨 구간이다.
- 스폰 시 스테이지별 HP/공격 기준을 적용한다. 일반 HP150/220/300, 정예·경호원205/295/400, 보스450/650/850. 기준 공격은 각각20/26/32, 24/30/38, 32/42/52. 무기 배율·산탄 분할은 기존 경로를 재사용한다. 실제 보스 패턴 전체의 연사 피해 예산 검증은 남는다.
- XP 지급·성장 계산·아이템 사용 레벨 제한을 비활성화했다. 기존 저장 필드/클래스는 호환용으로 보존한다. 모듈 슬롯은 저장된 퀘스트 슬롯 보상 수로 해금하며 기본2/최대8칸을 유지한다.
- 퀘스트에는 방문 스테이지 all-of 조건, 공유 성장 보상 그룹, 행동/제작/섹터·랜드마크 클리어 이벤트, 제작법 해금 필드를 추가했다. HOME NPC 직접 완료 규칙은 유지한다. 구조물 파괴 enum은 확장 지점이며 실제 무기 피해 기여 판정/배치 장치 연결을 완료했다는 뜻은 아니다.
- 개별 퀘스트 SO의 본문·목표·선행·영구 보상량은 변경하지 않았다. 따라서 S4 플레이어 HP280/공격65 목표가 현재 퀘스트에서 자동 달성되도록 보상을 재배분하지 않았다.

## 2. 제작·모듈 레시피·저장 — 코드 반영 / 콘텐츠 일부 미완

- Normal N3 / Rare R2+N1 / Unique U2+R1 / Legendary L2+U1+R1 / Mythic M2+L1+U1+R1+N1.
- 연결 카테고리·희귀도에서 특정 Valuable을 추첨해 고정 요구품으로 표시한다. 현재 요구품을 정확히 내야 하며 카테고리 아무 물건이나 대납하지 않는다. 제작 성공률100%, 완료 때만 해당 종류·등급의 다음 레시피로 갱신한다.
- HOME 제작 UI와 Crafting Maker를 추가했다. Item Maker의 제작 Maker 버튼 및 Game System Tool의 제작 메뉴에서 접근한다. 일반 고정 재료 제작도 등록할 수 있다.
- 결과 공간·재료·소유 상한·귀속/장착 모듈 소비 금지를 검사한다. 공간 계산은 보수적으로 차감 전 빈 공간을 요구한다. 비용으로 공간이 생길 예정이라도 현재 결과 공간이 부족하면 시작하지 않는다.
- 결과 인벤토리와 다음 레시피를 같은 run 저장 파티션에 먼저 기록하고 profile에 반영한다. 재접속 시 run 레시피 기록을 통해 profile을 복구한다. 제작 중 알림을 억제하고 저장 후 한 번 알린다. 최초 목록도 묶어서 저장한다. 실제 ES3 장애 주입 검증은 미실행이다.
- 현재 실효 모듈19종×5등급 = 95개 제작 설정, 기존 Valuable60개 승인 풀을 등록했다. 불활성 빈 모듈·테스트 모듈은 자동 제작 목록에서 제외했다.
- 피해 모듈10/15/20/30/45%, 관통·방탄1/2/3/5/7을 적용했다. 기존 부가 페널티는 보존했다. 다른 효과의 미식 수치를 임의로 발명하지 않았다.
- **데이터 감사에서 미설정 효과 등급17건이 확인됨:** 미식15종 + 도탄 Normal/Rare. 해당 제작은 사유를 표시하고 중단한다.
- **현재 승인 카테고리 풀의 Legendary/Mythic 공급이 부족해 38개 레시피가 미완이다.** 재료 요구 슬롯57건이 부족하다. 등급을 낮추거나 공짜로 제작하지 않는다. 카테고리·희귀도별 실제 물품을 정해 등록해야 한다.
- 추가 금액은 미정이라0의 편집 가능 값이다. 방탄복·탄약의 개별 제작 재료/가격/퀘스트 해금은 자동 작성하지 않았다.

## 3. 랜드마크 생성·지도·클리어 — 기반 코드 반영 / 기존 스테이지 OFF

- LandmarkDefinitionSO와 사전 제작 LandmarkPrefab을 추가했다. 1~4개의 연결된 논리 칸, 고유 ID/variant ID, 셀별 SectorRuntime/프리셋을 사용한다.
- 보장 랜드마크 전부를 비중복 배치하고 시작점에서 일반섹터 가지를 연결한다. 외곽 탈출은 일반섹터의 가지 끝에 붙인다. 작은 맵에서 가지가 부족하면 짧은 일반 가지를 추가한다. 공간 자체가 부족하면 명시적으로 실패한다.
- 보스는 적격 랜드마크 중 랜덤 배정한다. 기존 ‘보스가 탈출 경로 막지 않기’ 설정이 켜져 있으면 보스 랜드마크의 전체 점유 칸을 우회해 모든 외곽 탈출에 도달하도록 검사한다.
- 랜드마크는 지도 상시 공개·보스 배정 숨김. 외부 출입은 기존 포탈, 내부 연결은 사전 제작한 열린 공간을 걷는 방식이다. 전체 칸을 함께 열고 적을 활성화하며, 한 NavMesh로 묶어 빌드/엄폐 파괴 갱신한다.
- 전체 칸의 적·예정 웨이브 완료 후 묶어서 클리어한다. 일반 섹터 목표에는 칸 수, 특정 랜드마크 목표에는1을 보낸다.
- **실물 복합 프리팹/랜드마크 SO는 아직 제작·등록하지 않았다. 기존 StageDefinition의 새 모드는 OFF다.** 켜기 전 Stage Maker에서 발전소1개·유효 셀 프리셋·외부 출입구·스테이지 전용 일반맵을 등록해야 한다. 기존 공용/특별 SO는 삭제하지 않았다.
- S1~4 보스의 최종 이름·스테이지 재배치, 고유 방탄/관통 보너스, 복수 해치·제작 해금 장치의 실제 배치는 별도 콘텐츠 작업이 남는다. 구형 이름만 보고 다른 보스로 단정해 덮어쓰지 않았다.

## 4. 이동·소음·무게·공간 — 코드 반영 / 공간 재배치 미실행

- 중앙 포탈 활성화 요구를 OFF로 바꿨고 미클리어 자유 통과를 유지한다. 기존 장치 에셋을 삭제하지 않았다.
- 도착한 포탈의 역방향 재사용만5초 제한하며 다른 포탈은 잠그지 않는다. 안내에 남은 시간을 표시하고 남은 쿨을 저장한다. 기존 이동 준비5초는 별도 유지한다.
- 루팅 시작 시 고정75 반경의 Impact 소음을 기존 HFSM 청취→위치 조사 경로로 보낸다. 총성150의 절반을 첫 테스트값으로 둔 것이며 무기별 현재 소음에 연동하지 않는다. 반복 조사 소음·범위는 Play Mode에서 조정할 대상이다.
- 무게 수용량 = 플레이어 기본값 + 영구 CarryCapacityKg 보상 + 가방 보너스. 가방LV1~5의 시험 보너스는0/5/10/15/20kg. 기존70~100% 이상 패널티와 초과 소지는 유지한다.
- Sector Maker에 선택 프리팹의 바닥·경계·포탈 공간을1.2배로 저장하는 명시적 편집 도구를 추가했다. **기존 프리팹에는 실행하지 않았다.** 내부 소품·적/루팅 후보 지점·Room Spacing XZ(예:40→48)·NavMesh를 함께 확인해야 한다. 루팅 후보를 전 맵에 자동 재배치하지 않았다.

## 5. 일반 HFSM 근거리 팩션 발견 공유 — 코드 반영

- 실제 시각 발견 또는 기존 검증을 통과한 공격자 피격 보고가 공유를 발동한다. 소리 경계/조사만으로는 공유하지 않는다.
- 동일 팩션·평면 거리45 이내에만 전달한다. 가까운 개체라는 규칙을 따르며 같은 섹터 제한은 기본OFF(설정 가능), 시각 재공유 간격은0.5초 시험값이다.
- 수신 개체는 기존 HFSM의 추적/수색 흐름에 상대와 마지막 확인 위치를 전달받는다. 벽 너머 자동 사격이나 영구 실시간 위치 락을 부여하지 않는다. 자기 시야·사거리·사격 경로는 별도로 검사한다.
- 실제 새 목격 없이 공유받은 기억을 다시 방송하지 않는다. HFSM/웨이브 초기화 호출을 추가하지 않았다.
- **수풀의 감지·은폐·원형 시야·공격 노출 규칙은 전부 제외. 수풀 에셋/코드는 추가하지 않았다.**

## 보존/가정

- 현재 모듈 최대 8칸·HOME 변경 제한·중복 제한은 유지. 슬롯 해금은 퀘스트로 전환한다.
- 경험치 저장 필드는 옛 저장 호환용으로 보존하되 게임플레이 계산/지급에는 사용하지 않는다.
- 개별 퀘스트 SO, 본문, 상세 목표와 보상량을 자동 생성/재배분하지 않는다.
- 미정 수치는 인스펙터에서 조절 가능한 테스트값으로 구현하며 최종 밸런스로 주장하지 않는다.
- 이동 준비 시간과 도착 후 역방향 쿨타임은 별개다. 기존 준비 시간은 유지한다.
- 기존 저장된 맵과 기존 프리팹은 호환 경로를 보존한다. 랜드마크 실제 배치물/아트 제작과 시스템 구현을 구분한다.
