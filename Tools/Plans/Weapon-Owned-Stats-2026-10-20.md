# 무기 기본 스탯 소유권 이관 · 2026-10-20

## 원칙

무기 SO가 사격 기본값을 소유하고, 캐릭터 런타임은 무기 기본값에 장착 패시브/장비/퀘스트 보정을 합친 최종값만 제공한다.
예: 무기 조준속도 3 + 장착 패시브 FlatAdd 1 = 최종 조준속도 4.
다른 기본값 2인 무기로 바꾸면 같은 패시브를 유지한 채 3이 된다. 공유 무기 SO 자체는 수정하지 않는다.

## 실제 데이터와 코드

- RangedWeaponSO.Combat에 사거리, 초당 발사 수, 재장전 시간, 조준속도,
  일반/정조준 퍼짐, 조준 중 이속 배율, 추가 관통, 총성 반경,
  발사 반동 거리/누적 상한/초당 복구를 둔다.
- 탄창, 탄환 피해 배율, 헤드샷 배율, 내구도, 호환 탄종은 기존 무기 SO 소유권 그대로 유지.
- 근접 무기는 이미 MeleeWeaponSO에서 피해/범위/타이밍 등을 소유하므로 그 경로를 유지.
- 캐릭터 Config의 옛 사격 기본값은 숨긴 직렬화 호환 데이터로만 보관하고 계산에서 사용하지 않는다.
  체력/이속/스태미나/대시/시야/인벤토리/발소리/피격 반응은 캐릭터 쪽이다.
- 발사 반동과 피격 흔들림은 상태/복구를 분리. 기본 합산 상한이 두 배가 되지 않게 최종 조준 오프셋도 제한.
- 플레이어/적 모두 동일한 무기 기본값 및 발사 반동 규칙을 사용.
  적의 버스트/휴식/반응/추적/선호 거리/엄폐 판단은 기존 AI Config를 유지.
- 기존 공통 AimFeedback에는 피격 거리/상한/복구 및 적 피격 명중 저하만 노출한다.
- 스탯 ID는 재정렬하지 않고 38~41에 발사 반동 3종 및 조준 이속 최종 보정 ID를 추가.
  발사 반동 3종은 패시브 대상에 포함한다. 탄창/옛 반동 ID는 계속 제외.

## 이관 기준

실제 총기 13개와 권총 제작 템플릿 1개를 이관했다. 독립적인 새 밸런스를 임의로 만들지는 않았다.
기존 플레이어 기본값과 기존 무기별 배율을 절대값으로 접어 넣었다.

- 사거리 100, 재장전 2초, 조준속도 3, 비조준/정조준 퍼짐 36/4도.
- 조준 중 이속 .6, 총성 반경 150, 추가 관통 0.
- 발사 반동 .35, 상한 2, 복구 2.5/초에 기존 무기 반동 배율을 반영.
- 연사: 권총 7.8, 리볼버 5.46, SMG 15.6, AR 11.7, LMG 13.65,
  저격총 1.56, 산탄총 3.9, 로켓 발사기 2.34발/초.
- 기존 탄창/피해 배율/산탄 퍼짐/아이콘/프리팹/오디오/가격 등 나머지 무기 데이터는 보존.
- 같은 무기를 쓰는 적마다 달랐던 옛 사격 기본값은 더 이상 적용되지 않는다.
  Agent의 옛 캐릭터 관통 보너스 +1도 무기 기본값과 중복되는 옛 경로이므로 제외된다.
  적의 무기별 기본 성능은 이제 플레이어와 같고, AI 사격 타이밍과 행동 차이는 유지된다.

## 도구 및 검증 경계

- Item Maker/Inspector: 무기 기본 성능 묶음에서 직접 편집.
- 아이템 상세: 무기 자체의 기본 성능 표시. 장착 보정 후 최종값과 구분.
- Debug Monitor: 현재 무기 원본 및 최종 연사/재장전/조준/퍼짐/발사 반동 표시.
- 옛 메타 기본 스탯 표시에서는 무기 소유 행을 제외해 캐릭터 Config의 폐기값이 표시되지 않게 함.
- 정적 확인: 무기 데이터 14개 새 수치 비교 및 Combat 추가 외 나머지 데이터 보존 확인,
  활성 코드의 캐릭터 사격 기본값 참조와 옛 무기 연사/반동 배율 중복 적용 참조 없음 확인.
- 빌드, Unity 실행, 테스트 실행, AssetDatabase.Refresh는 수행하지 않음. 컴파일/Play 검증은 미실시.
