# 2026-10-22 패시브·포켓·총기 고장·임무 완료 패치

- 사망 시 소지품 초기화는 기존 원정 손실 경로를 유지한다. HOME 창고와 영구 해금은 지우지 않는다.
- 적도 같은 PassiveItemSO/개체별 효과/중복 제한을 사용한다. 가스 방호 첫 칸 + 역할별 추첨. 보스는 선택된 범위의 최대 수치. 적 패시브는 전투 스탯에 적용되며 시체 창에서 아이콘·효과를 보여주되 클릭/드래그/획득 경로는 없다.
- 총기 고장은 플레이어 사격 경로에 추가했다. 원작의 고장 종류·탄/탄창/과열 전체를 복제하는 작업은 아니다. 적 AI용 총기 고장은 추가하지 않았다.

## 테스트 콘텐츠와 설정 위치

`Assets/Resources/PassiveModuleRules.asset`: 등급별 분해 파츠, 분해 수량, 리롤 비용, 적 기본 가스 방호와 추첨 풀.

Item Maker의 패시브 화면에서 공용 설정을 바로 선택할 수 있다. `Assets/Resources/PassiveModules`의 임시 6종과 파츠도 Item Maker 목록에 포함한다. 임시 효과는 방탄·관통·가스 방호·체력·이속·조준 속도다. 최종 밸런스가 아니며 기존 루팅 테이블을 이 임시 풀로 교체하지 않았다.

기존 고정 패시브는 기존 효과를 보존했다. 해당 품목에도 리롤을 쓰려면 Item Maker에서 같은 효과의 등급별 범위를 등록해야 한다. 범위가 없는 품목은 안내만 표시하고 파츠를 소비하지 않는다. Normal 관통 테스트 모듈은 0.1~0.5다.

적 프로필은 Scraper 2칸/Normal, Raider 3칸/Normal~Rare, Agent 4칸/Rare~Unique. 현재 Punisher 및 Stage 1 임시 보스는 3칸/Normal~Rare, Stage 2 보스는 4칸/Normal~Rare, Stage 3 보스는 4칸/Rare. 기존 보스 모델·무장·맵은 바꾸지 않았다.

## 총기 고장 임시값

추가 확정: 플레이어의 성공한 발사 1회당 내구도 기본 감소량 0.05. 공발·고장으로 실제 발사되지 않은 경우에는 감소하지 않고, 산탄은 펠릿마다가 아니라 발사 1회에 한 번만 감소한다. 적은 고장 판정과 발사 내구도 소모가 없으며, 공용 장비 API도 적의 내구도 소모·고장 설정을 거부한다. 적 무기의 최초 내구도와 드롭 품질은 유지한다.

후속 요청 반영: 각 무기 SO의 고장 안전 경계 / 기준 내구도 / 기준 발수 / 기준 누적 고장 확률에서 수정한다. 기본값은 내구도 90% 이상 고장 없음, 90% 미만부터 1% 구간마다 발사당 고장 확률을 약 0.015906%p씩 더한다. [89%,90%)는 첫 구간이고 [88%,89%)는 두 번째 구간이다. 기준 내구도 30%에서 발사당 약 0.954357%, 같은 내구도로 30발 시도 시 한 번 이상 고장 날 확률 25%다. 공식은 `기준 발사당 p = 1 - (1 - 0.25)^(1/30)`, `현재 p = 기준 p × 현재 구간 수 / 60`. 실제 연사 중 내구도가 더 내려가면 이후 발사의 확률도 올라가므로 누적값은 조금 높아질 수 있다. 기존 93%/최대 12% 제곱식은 폐기했다.

고장 시 메시지 → T 한 번 → 이동 가능한 5초 진행바 → 사격 재개. 기능처치는 내구도 수리가 아니다. T는 고장 중에는 기능처치가 우선이고 평소에는 기존 탄종 전환이다. 무기 슬롯 선택과 저장/이어하기가 고장을 지우지 않는다. 고장 난 총기의 보관·판매·다른 총으로 교체는 기능처치 후 가능하며, 다른 무기 슬롯을 선택하는 것은 가능하다. 진행 중 슬롯 변경·사망·행동 차단은 처치를 취소한다. 공격과 재장전은 처치와 겹치지 않는다.

[참고한 고장 개념](https://escapefromtarkov.fandom.com/wiki/Weapon_malfunctions)은 저내구도와 고장의 연결 방향이며, 이 패치의 확률과 5초 처치는 Board Chase용 임시 규칙이다. 원작의 최신 공식 확률을 재현했다고 주장하지 않는다.
